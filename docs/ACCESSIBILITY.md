# Accessibility & Inclusive Design (WCAG 2.2 AA)

## 1. Visual Accessibility
- **Color Independence**: AQI categories and status indicators use color combined with text labels, icons, and distinct geometric badges.
- **Contrast Ratios**: Minimum 4.5:1 for normal text, 3:1 for large text and interactive component boundaries against backgrounds.
- **Text & Table Alternatives**: All charts (such as pollutant timelines) include accessible data table alternatives and plain-text summaries.

## 2. Interaction & Navigation
- **Keyboard Complete**: All journeys (selecting cities, entering routines, choosing candidate options, expanding details) are fully operable via Tab, Shift+Tab, Enter, Space, and Arrow keys.
- **Focus Management**: Modals and slide-overs trap focus when open, close cleanly on Escape, and restore focus to the triggering element.
- **Responsive Reflow**: Fully functional at 320px width without horizontal scrolling; scales up to 200% zoom seamlessly.
